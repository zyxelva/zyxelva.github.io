AP PreCalculus 第14课完整讲义：三角恒等式、极坐标与极坐标函数

（适配2025 College Board考纲，含教学流程、例题、真题、练习全解析）

一、课程基本信息

项目详情
课时2小时（120分钟）
所属单元Unit 3: Trigonometric and Polar Functions
对应考纲章节3.11（三角恒等式）、3.12（极坐标基础）、3.13（极坐标与直角坐标转换）、3.14（极坐标函数）、3.15（极坐标图像识别）
前置知识单位圆三角函数定义、诱导公式、三角函数图像性质、勾股定理
教学目标1. 掌握核心三角恒等式（倒数、商数、平方），能熟练化简和证明三角函数表达式
2. 理解极坐标的定义与表示方法，熟练进行极坐标与直角坐标的双向转换
3. 识别常见极坐标函数（圆、玫瑰线、心形线）的图像特征
4. 能根据极坐标方程绘制简单图像，或根据图像推导极坐标方程
教学重难点重点：三角恒等式应用、极坐标与直角坐标转换、常见极坐标图像识别
难点：三角恒等式证明的逻辑推导、极坐标方程与图像的互化、多值对应关系处理

二、教学流程（120分钟）

1. 导入环节（10分钟）

  • 情境引入：展示卫星轨道的极坐标示意图、玫瑰线艺术图案、三角恒等式化简实例，提问：“导航系统中为什么用极坐标描述位置更方便？如何用简洁的公式化简复杂的三角函数表达式？玫瑰线的极坐标方程有什么规律？”
  • 知识衔接：回顾上节课三角方程求解中用到的勾股恒等式（$\sin^2x+\cos^2x=1$），关联单位圆中三角函数的比值关系，引出更多三角恒等式；对比直角坐标系的“x-y定位”，提出极坐标“距离-角度定位”的优势，自然过渡到极坐标知识点。
  • 考纲提示：本课时内容占AP PreCalculus考试的12%-14%，三角恒等式化简、极坐标转换是选择题高频考点，极坐标图像识别常结合建模考查，是衔接大学数学的重要基础。

2. 核心知识点讲解（60分钟）

模块1：三角恒等式（20分钟）

关键术语：三角恒等式（Trigonometric Identities）、倒数恒等式（Reciprocal Identities）、商数恒等式（Quotient Identities）、平方恒等式（Pythagorean Identities）

  • 核心恒等式分类（必考）：
    1. 倒数恒等式（互为倒数关系）：
      • $\sec x = \frac{1}{\cos x}$（正割函数）
      • $\csc x = \frac{1}{\sin x}$（余割函数）
      • $\cot x = \frac{1}{\tan x} = \frac{\cos x}{\sin x}$（余切函数）
    2. 商数恒等式（比值关系）：
      • $\tan x = \frac{\sin x}{\cos x}$
      • $\cot x = \frac{\cos x}{\sin x}$
    3. 平方恒等式（由勾股定理推导，核心）：
      • $\sin^2x + \cos^2x = 1$（基础）
      • $1 + \tan^2x = \sec^2x$（两边除以$\cos^2x$）
      • $1 + \cot^2x = \csc^2x$（两边除以$\sin^2x$）
  • 恒等式应用（化简与证明）：
    • 化简原则：“切化弦”“统一角”“消去公因式”，优先使用基础恒等式。
    • 例题1：化简$\frac{\sin x \cdot \sec x}{\tan x}$
      解析：
      • 切化弦+倒数转换：$\sec x = \frac{1}{\cos x}$，$\tan x = \frac{\sin x}{\cos x}$；
      • 代入得：$\frac{\sin x \cdot \frac{1}{\cos x}}{\frac{\sin x}{\cos x}} = 1$；
      • 答案：$1$。
    • 例题2：证明$\sin^2x - \cos^2x = 2\sin^2x - 1$
      解析：
      • 左边：$\sin^2x - \cos^2x$；
      • 利用$\cos^2x = 1 - \sin^2x$代入：$\sin^2x - (1 - \sin^2x) = 2\sin^2x - 1$；
      • 左边=右边，证明成立。

模块2：极坐标基础与转换（25分钟）

关键术语：极坐标（Polar Coordinates）、极点（Pole）、极轴（Polar Axis）、极径（Polar Radius）、极角（Polar Angle）

  • 极坐标定义：
    • 极点：坐标原点$O$；
    • 极轴：与直角坐标系x轴正半轴重合的射线；
    • 极坐标表示：点$P$的极坐标为$(r, \theta)$，其中$r$为极径（点到极点的距离，$r$可正可负），$\theta$为极角（极轴到射线$OP$的角度，逆时针为正）。
  • 极坐标与直角坐标双向转换公式（核心考点）：
    1. 极坐标转直角坐标（$(r, \theta) \to (x, y)$）：
      • $\boldsymbol{x = r\cos\theta}$
      • $\boldsymbol{y = r\sin\theta}$
    2. 直角坐标转极坐标（$(x, y) \to (r, \theta)$）：
      • $\boldsymbol{r = \sqrt{x^2 + y^2}}$（$r$默认非负，特殊情况可取负）
      • $\boldsymbol{\tan\theta = \frac{y}{x}}$（$\theta$需结合点所在象限确定）
  • 转换例题：
    • 例题3：将极坐标$(2, \frac{\pi}{3})$转换为直角坐标
      解析：
      • $x = 2\cos\frac{\pi}{3} = 2 \times \frac{1}{2} = 1$；
      • $y = 2\sin\frac{\pi}{3} = 2 \times \frac{\sqrt{3}}{2} = \sqrt{3}$；
      • 直角坐标：$(1, \sqrt{3})$。
    • 例题4：将直角坐标$(-\sqrt{3}, 1)$转换为极坐标（$r>0$，$\theta \in [0, 2\pi)$）
      解析：
      • $r = \sqrt{(-\sqrt{3})^2 + 1^2} = \sqrt{3 + 1} = 2$；
      • $\tan\theta = \frac{1}{-\sqrt{3}} = -\frac{\sqrt{3}}{3}$，点在第二象限，故$\theta = \frac{5\pi}{6}$；
      • 极坐标：$(2, \frac{5\pi}{6})$。

模块3：极坐标函数与图像（15分钟）

关键术语：极坐标函数（Polar Function）、圆（Circle）、玫瑰线（Rose Curve）、心形线（Cardioid）

  • 常见极坐标函数及图像特征：
极坐标方程图像类型核心特征
$r = a$（$a>0$）圆圆心在极点，半径为$a$
$r = a\cos\theta$（$a>0$）圆圆心在$(\frac{a}{2}, 0)$（直角坐标），半径$\frac{a}{2}$，与极轴相切于极点
$r = a\sin\theta$（$a>0$）圆圆心在$(0, \frac{a}{2})$（直角坐标），半径$\frac{a}{2}$，与极轴垂直相切于极点
$r = a\cos(n\theta)$（$a>0$，$n$为正整数）玫瑰线$n$为奇数：$n$瓣；$n$为偶数：$2n$瓣
$r = a(1 + \cos\theta)$（$a>0$）心形线开口向右，顶点在$(2a, 0)$（极坐标），过极点
  • 图像绘制技巧：
    • 取特殊角$\theta = 0, \frac{\pi}{6}, \frac{\pi}{4}, \frac{\pi}{3}, \frac{\pi}{2}, \dots, 2\pi$，计算对应$r$值，描点连线；
    • 利用对称性（如$r = a\cos\theta$关于极轴对称）简化绘制。
  • 例题5：简述极坐标方程$r = 3\sin(2\theta)$的图像特征
    解析：
    • 类型：玫瑰线；
    • 瓣数：$n=2$（偶数），故4瓣；
    • 范围：$r \in [-3, 3]$，最大距离极点3个单位；
    • 对称性：关于极轴、极点、垂直极轴的直线均对称。

3. 真题实战与易错点剖析（30分钟）

近5年真题解析（每题6分钟，含思路梳理+评分点）

1. 2025年真题 Q26（选择题）

题目：Which of the following is equivalent to $\sin^2x + \cos^2x + \tan^2x$?
A. $\sec^2x$
B. $\csc^2x$
C. $\cot^2x$
D. $\tan^2x$
解析：

  • 考点：平方恒等式应用（核心评分点）
  • 步骤：① 利用基础恒等式$\sin^2x + \cos^2x = 1$；② 代入得$1 + \tan^2x$；③ 由平方恒等式$1 + \tan^2x = \sec^2x$；
  • 答案：A（评分点：应用两个平方恒等式各1分）
2. 2024年真题 Q30（选择题）

题目：Convert the polar coordinate $(4, \frac{3\pi}{4})$ to rectangular coordinates.
A. $(-2\sqrt{2}, 2\sqrt{2})$
B. $(2\sqrt{2}, -2\sqrt{2})$
C. $(-\sqrt{2}, \sqrt{2})$
D. $(\sqrt{2}, -\sqrt{2})$
解析：

  • 考点：极坐标转直角坐标（核心评分点）
  • 步骤：① $x = 4\cos\frac{3\pi}{4} = 4 \times (-\frac{\sqrt{2}}{2}) = -2\sqrt{2}$；② $y = 4\sin\frac{3\pi}{4} = 4 \times \frac{\sqrt{2}}{2} = 2\sqrt{2}$；
  • 答案：A（评分点：三角函数值计算1分，转换公式应用1分）
3. 2023年真题 Q35（解答题）

题目：Convert the rectangular coordinate $(-1, \sqrt{3})$ to polar coordinates with $r>0$ and $\theta \in [0, 2\pi)$.
解析：

  • 考点：直角坐标转极坐标（核心评分点）
  • 步骤：① 计算$r = \sqrt{(-1)^2 + (\sqrt{3})^2} = \sqrt{1 + 3} = 2$；② 计算$\tan\theta = \frac{\sqrt{3}}{-1} = -\sqrt{3}$，点在第二象限，故$\theta = \frac{2\pi}{3}$；
  • 答案：$(2, \frac{2\pi}{3})$（评分点：$r$计算1分，$\theta$计算1分，象限判断1分）
4. 2022年真题 Q23（选择题）

题目：Which polar equation represents a circle with center at $(1, 0)$ in rectangular coordinates?
A. $r = 2\cos\theta$
B. $r = 2\sin\theta$
C. $r = \cos\theta$
D. $r = \sin\theta$
解析：

  • 考点：极坐标方程与直角坐标圆的对应（核心评分点）
  • 步骤：① 圆心$(1, 0)$、半径1的直角坐标方程：$(x-1)^2 + y^2 = 1$，展开得$x^2 - 2x + 1 + y^2 = 1$；② 利用$x^2 + y^2 = r^2$、$x = r\cos\theta$代入，得$r^2 - 2r\cos\theta = 0$，化简为$r = 2\cos\theta$；
  • 答案：A（评分点：直角坐标方程推导1分，转换代入1分）
5. 2021年真题 Q37（选择题）

题目：Which of the following is the graph of $r = 2(1 - \cos\theta)$?
A. A cardioid opening to the left
B. A cardioid opening to the right
C. A rose curve with 2 petals
D. A circle with radius 1
解析：

  • 考点：极坐标函数图像识别（核心评分点）
  • 步骤：① 方程形式为$r = a(1 - \cos\theta)$，属于心形线；② 当$\theta = 0$时，$r = 2(1 - 1) = 0$；当$\theta = \pi$时，$r = 2(1 - (-1)) = 4$，故开口向左；
  • 答案：A（评分点：图像类型识别1分，开口方向判断1分）

高频易错点及应对措施

易错点类型具体错误表现解决方案
三角恒等式应用错误1. 混淆平方恒等式的变形（如误写$1 - \sin^2x = -\cos^2x$）
2. 化简时未统一角或函数名，导致逻辑混乱
3. 证明题缺乏步骤，直接等式替换		1. 核心恒等式默写：每天默写3组平方恒等式及变形，强化记忆
2. 化简口诀：“先切化弦，再用平方，最后消公因式”
3. 证明题步骤固化：“左边→中间过渡→右边”，每一步标注所用恒等式（如“由$\sin^2x+\cos^2x=1$得”）
4. 实例验证：化简后代入特殊角（如$x=\frac{\pi}{4}$）验证左右两边是否相等
极坐标转换错误1. 直角转极坐标时，$\theta$未结合象限判断（如$\tan\theta=1$时，误写$\theta=\frac{\pi}{4}$忽略第二、四象限）
2. 极径$r$取负时，极角判断错误
3. 转换公式记忆混淆（如误写$x = r\sin\theta$）		1. 转换公式贴墙：“$x=r\cos\theta$，$y=r\sin\theta$”“$r=\sqrt{x^2+y^2}$，$\tan\theta=y/x$”，反复背诵
2. $\theta$判断步骤：① 计算$\tan\theta$的参考角；② 根据$(x,y)$所在象限确定$\theta$（第一象限：$\alpha$，第二：$\pi-\alpha$，第三：$\pi+\alpha$，第四：$2\pi-\alpha$）
3. $r$负值处理：$r \lt 0$时，极角=原角$+\pi$，再按正常流程转换
4. 双向验证：转换后回代公式，验证是否还原原坐标
极坐标图像识别错误1. 混淆玫瑰线瓣数与$n$的关系（如$r=a\cos(2\theta)$误判为2瓣）
2. 心形线开口方向判断错误
3. 误将$r=a$与$r=a\cos\theta$的图像混淆		1. 图像特征表格：整理常见极坐标方程、图像类型、核心特征，每日翻看
2. 玫瑰线瓣数口诀：“$n$奇$n$瓣，$n$偶$2n$瓣”
3. 心形线开口判断：看方程中$\cos\theta$的符号，$1+\cos\theta$开口向右，$1-\cos\theta$开口向左；$\sin\theta$对应上下开口
4. 描点验证：遇到不确定的图像，取3-5个特殊角计算$r$，初步勾勒图像轮廓
恒等式证明逻辑错误1. 证明时“循环论证”（用待证明的恒等式推导前提）
2. 步骤跳跃，关键恒等式应用未说明
3. 只化简一边，未证明两边相等		1. 禁止循环：证明前列出已知恒等式（教材明确给出的），仅用这些推导
2. 步骤标注：每一步变形都注明依据（如“倒数恒等式”“平方恒等式”“代数化简”）
3. 双向化简：复杂题目可同时化简左右两边，直至得到相同表达式

4. 课堂小结与公式梳理（10分钟）

核心公式清单（按考点分类）

  1. 三角恒等式：
    • 倒数恒等式：$\boldsymbol{\sec x = \frac{1}{\cos x}}$，$\boldsymbol{\csc x = \frac{1}{\sin x}}$，$\boldsymbol{\cot x = \frac{1}{\tan x} = \frac{\cos x}{\sin x}}$；
    • 商数恒等式：$\boldsymbol{\tan x = \frac{\sin x}{\cos x}}$，$\boldsymbol{\cot x = \frac{\cos x}{\sin x}}$；
    • 平方恒等式：$\boldsymbol{\sin^2x + \cos^2x = 1}$，$\boldsymbol{1 + \tan^2x = \sec^2x}$，$\boldsymbol{1 + \cot^2x = \csc^2x}$。
  2. 极坐标与直角坐标转换：
    • 极→直：$\boldsymbol{x = r\cos\theta}$，$\boldsymbol{y = r\sin\theta}$；
    • 直→极：$\boldsymbol{r = \sqrt{x^2 + y^2}}$，$\boldsymbol{\tan\theta = \frac{y}{x}}$（$\theta$结合象限确定）。
  3. 常见极坐标方程与图像：
方程图像类型关键特征
$\boldsymbol{r = a}$（$a>0$）圆圆心在极点，半径$a$
$\boldsymbol{r = a\cos\theta}$（$a>0$）圆圆心$(\frac{a}{2}, 0)$，半径$\frac{a}{2}$
$\boldsymbol{r = a\sin\theta}$（$a>0$）圆圆心$(0, \frac{a}{2})$，半径$\frac{a}{2}$
$\boldsymbol{r = a\cos(n\theta)}$（$a>0$）玫瑰线$n$奇$n$瓣，$n$偶$2n$瓣
$\boldsymbol{r = a(1 \pm \cos\theta)}$心形线$\pm\cos\theta$对应左右开口

学习建议

  1. 恒等式专项练：每天练3道化简题+1道证明题，强化“切化弦→平方恒等式→化简”的流程；
  2. 转换口算练：随机写10组极坐标/直角坐标，快速口算出转换结果，提升熟练度；
  3. 图像对照记：将常见极坐标方程与图像打印出来，对照记忆，重点关注特殊角对应的$r$值；
  4. 错题归类改：将“恒等式混淆”“转换象限错误”“图像识别错误”的题目分类，标注错误原因，每周复盘。

5. 课后作业（分层设计）

基础题（必做）

  1. 化简下列三角函数表达式：
    • $\frac{\sec x \cdot \sin x}{\tan x}$
    • $\sin^2x \cdot \sec^2x - \sin^2x$
  2. 完成下列坐标转换：
    • 极坐标$(3, \frac{5\pi}{6}) \to $ 直角坐标
    • 直角坐标$(-2, -2) \to $ 极坐标（$r>0$，$\theta \in [0, 2\pi)$）
  3. 识别下列极坐标方程的图像类型：
    • $r = 4$
    • $r = 2\sin(3\theta)$
    • $r = 1 + \sin\theta$

提升题（选做，对接AP解答题）

  1. 证明：$\frac{\cos x}{1 - \sin x} = \sec x + \tan x$（提示：分子分母同乘$1 + \sin x$）
  2. 已知极坐标方程$r = 4\cos\theta$，将其转化为直角坐标方程，并求出圆心和半径。
  3. 绘制极坐标方程$r = 2(1 + \sin\theta)$的图像（标注3个关键 points 的极坐标与直角坐标）。

三、教学资源配套

  1. 课堂板书模板：分“三角恒等式”“极坐标转换”“极坐标图像”“真题解析”四大板块，预留公式和例题书写区；
  2. 恒等式速记卡：浓缩核心三角恒等式及常见变形，方便碎片化记忆；
  3. 极坐标图像对照图：打印常见极坐标方程与对应图像，标注关键特征；
  4. 课后练习答案解析：含详细步骤和易错点标注，便于学生自查自纠。
